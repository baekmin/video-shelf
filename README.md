# 영상 책장 (video-shelf)

아이용 선별 유튜브 앱. 부모가 승인한 채널·카테고리만 보이고, 검색·추천·자동재생·쇼츠가 없는 "피드 없는 도서관".

- `index.html` — 앱 전체 (단일 파일). GitHub Pages로 서비스.
- `config.json` (선택) — 부모 설정 탭의 '내보내기' 결과를 이 이름으로 올려 두면 모든 기기가 같은 설정을 자동으로 받습니다. 공개 저장소이므로 API 키는 포함하지 마세요.

설정 순서: YouTube Data API v3 키 발급 → 앱의 부모님 설정에 입력 → 채널 검색·승인 → 카테고리 배치 → 아이패드 사파리에서 '홈 화면에 추가'.

## 광고 없이 보기 (프리미엄 계정 적용)

플레이어는 기본적으로 `youtube.com` 임베드를 쓰므로, 그 브라우저에 로그인된 유튜브 계정이 프리미엄이면 광고가 나오지 않습니다. 아이패드에서 적용되려면:

1. 사파리에서 youtube.com에 프리미엄 계정으로 로그인해 둔다.
2. 설정 → Safari → 개인정보 보호 및 보안 → **크로스 사이트 추적 방지 끄기** (켜져 있으면 플레이어 안에서는 로그아웃 상태로 취급돼 광고가 나옴).
3. 홈 화면 아이콘은 사파리에서 열린다(독립 실행 앱은 사파리와 로그인이 분리되므로 일부러 그렇게 둠).

부모님 설정 → 재생 계정에서 이 동작을 끄면 로그인과 무관하게(광고 있음, 시청 기록 안 남음) 재생합니다.

## 아이 기기 잠그기 (스크린타임)

- 유튜브 앱 삭제 + 콘텐츠 및 개인정보 보호 제한 → iTunes 및 App Store 구입 → 앱 설치 허용 안 함
- 콘텐츠 제한 → 웹 콘텐츠 → **허용된 웹 사이트만** → `baekmin.github.io` 추가 (youtube.com은 넣지 않음)
- 적용 후 앱에서 영상이 재생되는지 한 번 확인 (임베드 플레이어는 보통 계속 재생됨)
