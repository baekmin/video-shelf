# 영상 책장 (video-shelf)

아이용 선별 유튜브 앱. 부모가 승인한 채널·카테고리만 보이고, 검색·추천·자동재생·쇼츠가 없는 "피드 없는 도서관".

- `index.html` — 앱 전체 (단일 파일). GitHub Pages로 서비스.
- `config.json` (선택) — 부모 설정 탭의 '내보내기' 결과를 이 이름으로 올려 두면 모든 기기가 같은 설정을 자동으로 받습니다. 공개 저장소이므로 API 키는 포함하지 마세요.

설정 순서: YouTube Data API v3 키 발급 → 앱의 부모님 설정에 입력 → 채널 검색·승인 → 카테고리 배치 → 아이패드 사파리에서 '홈 화면에 추가'.
